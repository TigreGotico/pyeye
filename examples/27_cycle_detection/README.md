# 27 — Graph Algorithms: Cycle Detection

**Topic:** Graph cycle detection
**Key concepts:** Transitive closure, self-reachability, acyclic/cyclic classification

Use forward-chaining transitive closure to compute reachability in a directed graph. A node is cyclic if it can reach itself.

