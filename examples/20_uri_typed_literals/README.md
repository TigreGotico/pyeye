# 20 — URI Manipulation & Typed Literals

**Topic:** IRIs & typed data
**Key concepts:** `log:localName`, `log:namespace`, `log:dtlit`

log:uri converts any term to its string representation (IRI string). log:dtlit constructs typed literals (combining a value with a datatype IRI).

Run:

```bash
python uri_literals_demo.py
```
