# 32 — Decision Support / Scoring

**Topic:** Multi-criteria scoring
**Key concepts:** Weighted composite score, tier assignment (approve/review/reject)

A multi-criteria scoring system for loan applications. Each applicant has income, credit score, and employment years. Rules derive a weighted composite :score, then assign a :tier (approve / review / reject).

Run:

```bash
python scoring_demo.py
```
