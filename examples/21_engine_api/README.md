# 21 — Direct Engine API

**Topic:** Direct Engine API
**Key concepts:** `Engine`, `add_triple`, `add_rule`, `backward_chain`

The ``execute()`` function covers most use cases, but the ``Engine`` class can be used directly for fine-grained control: inspecting derived triples, querying the store, building the engine programmatically, and reusing it across multiple runs.

Run:

```bash
python engine_api_demo.py
```
