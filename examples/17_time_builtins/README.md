# 17 — Time Builtins

**Topic:** Date & time reasoning
**Key concepts:** `time:now`, `time:year`, `time:month`, `time:hour`

The time: namespace provides temporal reasoning: current timestamp, and extraction of individual date/time components from ISO 8601 strings.

Run:

```bash
python time_demo.py
```
