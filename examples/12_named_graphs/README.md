# 12 — Named Graphs (TriG)

**Topic:** Multiple graph contexts
**Key concepts:** TriG `GRAPH {}`, quad store, named-graph scoping

pyeye supports TriG syntax for associating triples with a named graph IRI. Rules can be graph-aware: match quads (triple + graph context).

Run:

```bash
python named_graphs_demo.py
```
