# 34 — Recursive Data Structures: Bill of Materials

**Topic:** Recursive BOM roll-up
**Key concepts:** Transitive part-of, collectAllIn sum, weight/cost propagation

A Bill of Materials (BOM) tree: products are assembled from components, which may themselves be assemblies. Compute total weight and total cost by recursively summing component values.

Run:

```bash
python bom_demo.py
```
