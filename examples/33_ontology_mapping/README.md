# 33 — Ontology Mapping / Schema Alignment

**Topic:** Ontology mapping
**Key concepts:** schema.org ↔ local vocab, bidirectional bridge rules, cross-vocabulary queries

Map between two vocabularies: schema.org and a local product ontology. Input data uses schema.org terms; mapping rules derive local-ontology equivalents so that both vocabularies work for queries.

Run:

```bash
python mapping_demo.py
```
