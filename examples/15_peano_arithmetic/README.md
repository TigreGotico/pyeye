# 15 — Peano Arithmetic via Backward Chaining

**Topic:** Recursive arithmetic
**Key concepts:** Deep backward chaining, tabling, `ReasoningTimeoutError`

The classic EYE demonstration of recursive backward chaining: natural numbers defined inductively using the Peano encoding, with addition, multiplication, and factorial defined via pure backward rules.

Run:

```bash
python peano_demo.py
```
