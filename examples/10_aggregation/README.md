# 10 — Aggregation: collectAllIn and forAllIn

**Topic:** Collect & count
**Key concepts:** `log:collectAllIn`, `log:forAllIn`, `list:length`

log:collectAllIn collects all solutions to a sub-pattern into an RDF list, then lets you use list: builtins (length, sum, member) on the results.

Run:

```bash
python aggregation_demo.py
```
