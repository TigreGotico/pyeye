# 07 — OWL 2 RL Entailment

**Topic:** OWL 2 RL properties
**Key concepts:** `entail_owl=True`, `owl:inverseOf`, `owl:sameAs`

entail_owl=True activates OWL 2 RL reasoning (a tractable subset of OWL 2 designed for rule-based engines). It implies entail=True (RDFS is included).

Run:

```bash
python owl_demo.py
```
